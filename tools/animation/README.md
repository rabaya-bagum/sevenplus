# Exercise animations

The 3D character clips in `SevenPlus/Resources/ExerciseClips/` are generated by these scripts:
a jointed mannequin built in code, posed with a few key poses per exercise, rendered in Blender
and encoded as small looping MP4s (light and dark versions) plus list thumbnails.

| File | What it does |
| --- | --- |
| `mannequin.py` | Builds the character (meshes on joints) and maps pose keys to joint rotations |
| `exercises.py` | Key poses for all 22 exercises — edit here to change a movement |
| `clips.py` | Pose solver (keeps hands/feet planted), keyframing, rendering, MP4 encoding |
| `stage.py` | Lighting, backdrop, camera framing, light/dark compositing |
| `render_all.py` | Renders every clip (or the ids you pass) |
| `thumbnails.py` | Makes `<id>-thumb.jpg` / `<id>-dark-thumb.jpg` from the clips |
| `preview.py` | Quick 6-frame contact sheets for checking poses |

## Setup (once)

Python 3.13 (matches the `bpy` wheel), plus ffmpeg on your PATH:

```bash
cd tools/animation
python3.13 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

## Change or add an exercise

1. Edit (or add) its function in `exercises.py` and add it to `ALL`. The id must match the
   exercise id in `ExerciseLibrary.swift`.
2. Check the poses: `.venv/bin/python preview.py /tmp/preview squat` → open `/tmp/preview/sheet_squat.png`.
3. Render it: `.venv/bin/python render_all.py ../../SevenPlus/Resources/ExerciseClips squat`
4. Thumbnails: `.venv/bin/python thumbnails.py ../../SevenPlus/Resources/ExerciseClips`

`ExerciseMediaTests` fails if any exercise is missing a clip or thumbnail.

## How a pose is described

Each key is a dict of joint angles in degrees (see *POSE KEYS* in `mannequin.py`) plus what must
hold, for example:

```python
{"t": 0.5, "pose": down,                      # halfway through the loop
 "support": TOES,                             # these touch the floor (or `height`)
 "free": ["both:sh_flex", "both:elbow"],      # angles the solver may adjust...
 "goals": [{"parts": PALMS, "z": 0},          # ...so the palms stay on the floor
           {"parts": PALMS, "xy": "first"}]}  # ...where they were in the first key
```

## Look

Workbench renderer (fast, no GPU needed), "paint" studio light, character composited over a
clean gradient with its real floor shadow. Colours live in `COLORS` (`mannequin.py`) and
`THEMES` (`stage.py`). A full render of all 22 clips takes about 45 minutes on 2 CPU cores.
